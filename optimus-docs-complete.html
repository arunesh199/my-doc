Crawling In-Depth

Spider class internals — entry points, request types, validation, pagination, and exception hierarchy.

Spider skeleton — main.py
from crawling_framework import Spider, Request, Response
from crawling_framework.requests import CurlcffiRequest, HttpxRequest
from crawling_framework.models import CreateTask

class WalmartCrawler(Spider):

    async def start_placement_request(self, request: Request):
        # Entry point for module="placement" tasks in local_config.yml
        yield CurlcffiRequest(
            url=request.url,
            impersonate="chrome130",
            callback=self.parse_listing,
            validate_response=self.validate_request,
            meta={"user_data": request.user_data}
        )

    async def validate_request(self, response: Response) -> bool:
        if response.status != 200: return False
        if "Access Denied" in response.text: return False
        return True   # False triggers automatic retry

    async def parse_listing(self, response: Response):
        # Pagination: yield CreateTask to queue next pages
        next_url = self.get_next_page(response.text)
        if next_url:
            yield CreateTask(url=next_url)
Request types
HttpxRequest Fastest
Simple HTML or REST APIs, no JS. Params: method, params, data, json_data
CurlCffiRequest Recommended
Impersonates Chrome/Firefox. Bypasses basic bot protection. Set impersonate="chrome130".
PlaywrightRequest Deprecated
Full browser. Use camoufox or nodriver instead.
Common request parameters
ParameterTypeDescription
urlstrTarget URL. Auto-validated by Pydantic.
headersdictHTTP headers.
cookiesdictCookies to send.
callbackmethodCalled with Response after download.
metadictPass data from request to callback.
proxystrhttp://user:pass@host:port
timeoutintTimeout in seconds.
validate_responsemethodCustom validation. False → retry.

}

Exception hierarchy
DownloaderError (Base) ├── RequestInitializationError # URL invalid, Pydantic fail ├── ResponseValidationError # validate_response returned False ├── CallbackExecutionError # error inside callback ├── ProxyManagerError # proxy issues ├── RetryExhaustError # all retries exhausted ├── RequestChainError # chained request failure └── CookiesValidationError # cookie generation/validation failed

Parsing In-Depth

ParserAbstract class — processes .pf_chain files and extracts structured data into Parquet.

Parser skeleton — main.py
from parsing_framework import ParserAbstract
from parsing_framework.helpers.lxml_parser import LxmlParser
from parsing_framework.models import ParsedResponse, PlacementProductDataItem

class WalmartParser(ParserAbstract):

    async def start_parse_placement(self, requests):
        # self.shop.code, self.shop.id — shop metadata available
        # self.task.breadcrumb, self.task.url — task metadata available
        items = []
        for request in requests:
            tree = LxmlParser(request.response)
            products = tree.xpath('//div[contains(@class,"product-item")]')
            for rank, product in enumerate(products, 1):
                name = product.xpath('.//span[@class="product-title"]/text()')
                price = product.xpath('.//span[@class="price"]/text()')
                if name and price:
                    items.append(PlacementProductDataItem.from_dict(
                        request=request, task=self.task,
                        data={"product_name": name[0], "price": price[0], "rank": rank}
                    ))
        return ParsedResponse(data_items=items, sub_tasks=[])
Parser libraries
LxmlParser Fastest
XPath selectors. Best for well-formed HTML/XML.
tree.xpath('//a[@class="title"]/text()')
Bs4Parser
CSS selectors + BeautifulSoup4. Best for malformed HTML.
soup.css('li.product-item')
PraseraParser AI-powered
Natural language — no selectors. Best for unstable pages or rapid prototyping.
PraseraParser (AI) example
from parsing_framework.helpers.paresra_parser import PraseraParser

attributes = {
    "product_name": "What is the name of the product?",

DataItem type hierarchy
DataItem (base — has data_type + strategy) ├── PlacementProductDataItem # product ranking data ├── PlacementCategoryDataItem # category / breadcrumb ├── PricingDataItem # price, promo, availability ├── RRQDataItem # ratings, reviews, Q&A └── CrTreeDataItem # category tree / site structure

    validate_response=self.validate_request,

2. Browser-based (camoufox or nodriver)
camoufox Recommended
Firefox-based. Install: crawling_framework[camoufox]. Shares BrowserSession interface with nodriver.
nodriver
Chrome via CDP. Install: crawling_framework[nodriver]. Avoids CDP-detectable automation.
3. Captcha solver modules
captcha_solver.external
Classic captchas (text, hCaptcha, GeeTest). Sends to Decaptcha via RabbitMQ. Install: crawling_framework[external]
captcha_solver.browser
Interactive: Cloudflare, DataDome, PerimeterX. Drives real browser via opencv + pyautogui. Install: crawling_framework[camoufox]
Supported captcha types
TypeClassNotes
Amazon image captchaAmzSimpleDecaptcherDistorted text in image. Test endpoint: httpbin.nonprod.profitero.dev/captcha/amz-simple
hCaptchaHcaptchaDecaptcherSends URL + sitekey → returns token
GeeTest v3GeetestDecaptcherSends URL + gt + challenge → returns solved response
⚠Captcha flow: GET page → 302 redirect → parse token → RabbitMQ → get answer → POST → clearance cookie. Set timeout ≥ 120000ms in cookies_options.

Session & Cookie Management

Automated cookie lifecycle via cookies_options in request meta.

Full cookies_options config
yield CurlcffiRequest(
    url=target_url,
    meta={
        "user_data": request.user_data,
        "cookies_options": {
            "enabled": True,
            "bind_proxy": True,         # same proxy reused with same cookies
            "cookies_identifier": zipcode,  # cache key — same id = shared cookies
            "valid_count": 5,             # max reuses before forced regeneration
            "timeout": 5000,              # seconds until cookies expire
            "cookies_callback": self.search_for_store,
            "validate_cookies": self.validate_cookies,
        },
    },
)
3-step cookie generation (store/zipcode)
async def search_for_store(self, request):
    yield CurlcffiRequest(url=search_url, callback=self.select_store)

async def select_store(self, response):
    stores = json.loads(response.text)
    store = self.find_store(stores)
    self.store_id = store.get("id", "")
    yield CurlcffiRequest(url=confirm_store_url, callback=self.store_confirm)

async def store_confirm(self, response):
    resp_json = json.loads(response.text)
    if response.status_code == 200 and resp_json.get("success"):
        yield CookiesModel(cookies=response.cookies)
    else:
        yield CookiesModel(cookies={"Invalid": "True"})

async def validate_cookies(self, cookies: dict) -> bool:
    return cookies.get("Invalid") != "True"
bind_proxy: True
Same proxy-cookies pair for all requests with same cookies_identifier. Consistent session.
bind_proxy: False
Proxy rotates per request even with same cookies. More IP diversity.

CR Tree Scheduling

CRON-based category tree collection configured via DB and DAG system.

Set schedule in shops table
-- Set CRON (e.g. every Monday at midnight)
UPDATE shops
SET cr_tree_recrawl_schedule = "0 0 * * 1"
WHERE shop_id = <shop_id>;

-- Verify shop is ready:
SELECT id, cr_tree_recrawl_schedule, cr_tree_recrawl_next_time
FROM shops
WHERE production = 'Y' AND active = 'Y'
  AND cr_tree_recrawl_schedule IS NOT NULL
  AND id = <shop_id>
  AND code_namespace LIKE 'Python::%';
DAG pipeline
DAGTriggerPurpose
cr_tree_collection_schedulerHourlySelects ready shops → triggers cr_tree_collector
cr_tree_collectorManual or autoCreates task with seed URL. Params: module, shop, day_in_shop_tz, ttl
cr_tree_landing_listenerHourlyChecks GCS for new Parquet → triggers cr_tree_loader
cr_tree_loaderTriggered by listenerConverts + loads Parquet into site_tree DB table
